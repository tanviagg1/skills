Turn a plain English description into a Jira or Linear ticket draft.

Follow these steps:

1. Ask me to describe the feature, bug, or task in plain English.

2. Ask me: is this a bug, feature, task, or improvement?

3. Generate a ticket draft:

   **Title:** Short, action-oriented, under 60 characters.

   **Type:** Bug / Feature / Task / Improvement

   **Description:**
   A clear explanation of what needs to be done and why.

   **Acceptance Criteria:**
   - [ ] Specific, testable conditions that mean this is done
   - [ ] Written as "Given / When / Then" or checkbox list

   **Technical Notes:** (if applicable)
   - Relevant files, services, or APIs involved
   - Known constraints or risks

   **Story Points (estimate):**
   Suggest 1 / 2 / 3 / 5 / 8 based on complexity.

4. Ask if I want to adjust the scope or break it into smaller tickets.
