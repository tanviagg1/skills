Add documentation to a function or file I specify.

Follow these steps:

1. Ask me which function or file to document.

2. Read the file. Understand what the function does, its parameters, return value, and any side effects.

3. Detect the language and use the standard doc format:
   - JavaScript/TypeScript: JSDoc
   - Python: Google-style docstring
   - Others: closest equivalent

4. Write the docstring/comment covering:
   - One-line summary of what the function does
   - Each parameter: name, type, description
   - Return value: type and description
   - Raises/throws if applicable
   - A usage example if the function is complex

5. Add the documentation to the file without changing any logic.
