Help me debug a problem systematically.

Follow these steps:

1. Ask me to describe the bug: what I expected, what actually happened, and any error messages.

2. Ask me to share the relevant code or file path.

3. Read the file(s) involved.

4. Reproduce the issue mentally — trace the code path that leads to the bug.

5. Identify the most likely root cause. Explain it clearly in plain English.

6. List 2-3 possible fixes ranked by simplicity.

7. Apply the simplest fix and explain what changed and why.

8. Suggest how to verify the fix works (what to run or test).
