1. Ask me which function or file to write tests for.

2. Read the file. Identify the function's inputs, outputs, and edge cases.

3. Write tests covering:
   - Happy path (expected input → expected output)
   - Edge cases (empty input, null, zero, boundaries)
   - Error cases (invalid input, exceptions)

4. Use the testing framework already in the project. Check package.json or requirements.txt to detect it (Jest, Vitest, pytest, etc.).

5. Follow the naming and file structure convention already used in the project for test files.

6. Write the test file and show me where it was saved.

7. Tell me the command to run the tests.
